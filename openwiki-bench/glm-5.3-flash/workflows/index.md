# Files

- [Automations Workflow](automations.md) - Scheduled and event-driven agent runs — the shared trigger registry, the D1-backed every-minute scheduler, invocation/run fan-out across repositories and environments, condition matching, concurrency and dedup, failure auto-pause, and Slack completion notifications.
- [Git Auth and Pull Requests Workflow](git-auth-and-pull-requests.md) - SCM credential brokering to sandboxes, the provider-generated push-spec flow, per-branch pull request creation with force-push reuse, GitHub PR lifecycle webhooks, the GitHub autofix queue, and commit attribution/signing.

- [Session Creation Workflow](session-creation.md) - End-to-end session creation — the POST /sessions route in order (input parsing, identity enforcement, repository/environment resolution, SCM enrichment, provider auth, managed skills), D1-first initialization with DO init and rollback, the spawn handoff to the lifecycle manager, and the child-session spawn path with its guardrails.
