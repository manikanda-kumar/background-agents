# Files

- [Control Plane Worker](control-plane-worker.md) - The Cloudflare Worker shell of the Open-Inspect control plane — its fetch/scheduled/queue entrypoints, API router and route groups, authentication edges, the D1 store layer, background-task seam, cron schedulers, and queue consumers.
- [Data Model & Storage](data-model.md) - Where Open-Inspect state lives — the shared D1 schema and its migrations, the per-session Durable Object SQLite schema, the per-aggregate D1 stores, R2 media storage and KV caches, and the encryption keys that protect tokens and secrets at rest.
- [Architecture Overview](overview.md) - The three-tier shape of Open-Inspect — clients, the Cloudflare control plane, and the sandbox data plane — including the WebSocket chains that connect them, the end-to-end prompt data path, the package dependency graph, and where each kind of state lives.
- [Sandbox Providers & Infra](sandbox-providers.md) - The SandboxProvider abstraction and its five implementations (Modal, Daytona, Vercel, OpenComputer, E2B), the control-plane lifecycle manager that decides spawn/restore/resume/snapshot through pure decision functions, and the per-provider infrastructure packages that build base images.
- [Sandbox Runtime](sandbox-runtime.md) - The Python in-sandbox runtime — supervisor composition, OpenCode server and prompt streaming, the agent bridge WebSocket protocol, repository boot, credential helper, managed skills, and installed agent tools.
- [Session Durable Object](session-durable-object.md) - The per-session SessionDO Durable Object runtime — its narrow platform adapter and composition graph, DO-embedded SQLite schema, hibernating WebSocket hub, message queue, event stream and cursors, presence, the single-slot alarm scheduler and its deadlines, session-status transitions, and the outbound completion callbacks.
- [Shared Contracts](shared-contracts.md) - The @open-inspect/shared package — the dependency-root TypeScript package that owns the sig1 service-auth format, the zod boundary schemas behind the WebSocket and sandbox-event protocols, the triggers registry, cron utilities, the model catalog, and the logger, plus the two-barrel export layout and the module-boundary test that enforces it.
- [Web Client](web-client.md) - The Next.js web package (`packages/web`) — its app-router structure, the browser-auth boundary proxied to the control plane, the signed BFF proxy routes, the session-socket state core behind the session page, the dashboard and settings surfaces, and the Vercel/Cloudflare build-time split.
